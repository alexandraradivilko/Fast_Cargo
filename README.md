# Fast Cargo

Проектная работа спринта 8: архитектурная трансформация логистической компании Fast Cargo при интеграции с холдингом «Плюс Ритейл».

## Задание 1. План архитектурной трансформации

[План трансформации](Task1/architecture-transformation-plan.md): бизнес-выгоды, AS-IS и TO-BE, границы и ограничения, переходная архитектура на три месяца, дорожная карта на год, критерии приёмки и откат.

## Задание 2. Подготовка к защите

- [Матрица стейкхолдеров](Task2/stakeholder-matrix.md): требования, приоритеты, влияние, риски и способы выполнения.
- [Ответы на возражения](Task2/objections-and-responses.md): позиция техлида Fast Cargo, информационной безопасности и инфраструктурного департамента холдинга.

## Задание 3. Метрики эксплуатации

- [Панель KPI](Task3/operational-kpi-dashboard.md): целевые значения, способы измерения и бизнес-смысл.
- [Вывод для генерального директора](Task3/ceo-performance-argument.md): performance argument и условия подтверждения окупаемости.

Материалы описывают проектные решения и целевые показатели учебного кейса. Дополнительные параметры, требующие согласования, отмечены в документах.
